# StoriLeaf open-book gallery placeholders

These six local SVG files are temporary illustrations in the public frontend-only GitHub Pages preview. They are **not photographs** of actual StoriLeaf books. The final founder-supplied open-book photographs will replace them later, one per book.

The gallery data is defined in `assets/content-sections-CfrmOVRI.js`. Each entry has its own image path, name and descriptive alt text. Once real book images are approved, add them under this public project's `gallery/` directory and change each corresponding path in that data, preferably using photographs of at least 1200 pixels across. The thumbnail uses a 3:2 crop, while the lightbox uses `object-fit: contain` to show the entire source image.

The six slots are Life Story, Travel Memoir, Relationship Memoir, Founder's Memoir, Parent to Child Letters and Celebrating Occasions. Do not upload private customer content or production secrets to this public repository.
